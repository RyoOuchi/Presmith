# Presmith v0.2.2

This prerelease bundles the updated Presmith Codex skill in the CLI and the
optional plugin. The skill adds requirements for consistent visual direction
throughout a presentation.

## Updated skill

- Establish a concrete visual system before authoring: backgrounds, typography,
  spacing, palette, image treatment, and chart styling.
- Create and inspect the cover, a typical content slide, and the most complex
  evidence slide before extending the design to the full deck.
- Keep backgrounds, shared design tokens, equivalent elements, and color meanings
  consistent while varying composition and information density.
- For substantial redesigns, improve hierarchy, composition, and visual explanation.
- Review contact sheets for visual unity and compare representative slides with
  the original. Successful exports and technical checks alone do not satisfy
  visual review.

The complete updated skill and all references are included in projects created
by `presmith init` and in `presmith skill install --global` installations.

## Upgrade

```sh
brew update
brew upgrade ryoouchi/tap/presmith
presmith --version
```

Refresh a previously installed global skill with:

```sh
presmith skill install --global --force
```

A different existing global copy is backed up before replacement. Identical copies
remain untouched. New decks automatically receive the updated skill; upgrading
the CLI does not rewrite skills already copied into existing projects.

## Downloads

- `presmith-v0.2.2-aarch64-apple-darwin.tar.gz`: CLI with the updated embedded skill,
  installation guide, licenses, and build information.
- `presmith-plugin-v0.2.3.tar.gz`: optional plugin containing the same updated skill.
- `SHA256SUMS`: SHA-256 hashes of both archives.

See the [installation guide](https://github.com/RyoOuchi/Presmith/blob/v0.2.2/docs/install.md).
Platform requirements remain Apple Silicon macOS 14 or newer. Homebrew supplies
Node.js 24 for browser operations. Skill installation and deck initialization
work offline. The CLI remains unsigned and unnotarized by Developer ID.
