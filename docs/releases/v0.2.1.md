# Presmith v0.2.1

This prerelease bundles the complete Codex skill in the CLI and shares renderer
dependencies across decks, reducing installation steps and repeated downloads.

## What's changed

- `presmith init my-talk` now includes `.agents/skills/presmith/`, with the full
  skill, all references, and Codex picker metadata. Open the project in
  Codex and use `$presmith` without downloading a separate skill.
- `presmith skill install --global` installs the embedded skill into
  `~/.agents/skills/presmith/` offline. Identical installations stay untouched.
  `--force` backs up a different or customized copy before replacement.
- `presmith setup` shares pinned npm packages and Chromium across matching decks.
  Existing local installations migrate on their next setup. `--local` keeps an
  installation inside one deck; `PRESMITH_CACHE_DIR` selects another cache location.
- Cache and skill installation protect existing files with staging, locks,
  validation, backups, and recovery on failure.
- Expanded command documentation and recipes cover creating presentations from
  briefs, scripts, structures, documents, data, existing decks, and demos.
- Added skill installation and shared-cache regression coverage, including offline
  operation, customization preservation, migration, reuse, and local opt-out.

## Upgrade with Homebrew

```sh
brew update
brew upgrade ryoouchi/tap/presmith
presmith --version
```

For a new installation, use `brew install ryoouchi/tap/presmith`.
To make the skill available across existing projects:

```sh
presmith skill install --global
```

If an existing global skill differs, add `--force` to save a backup and replace it.
Updating the CLI does not rewrite skills already copied into existing projects.
Run `presmith setup` in an existing deck to use the shared cache. Authored slides,
styles, scripts, and assets are preserved.

## Downloads

- `presmith-v0.2.1-aarch64-apple-darwin.tar.gz`: Apple Silicon macOS CLI, including
  the embedded skill, licenses, installation guide, and build information.
- `presmith-plugin-v0.2.2.tar.gz`: optional standalone plugin; the plugin has an
  independent version and is not required for the embedded skill.
- `SHA256SUMS`: SHA-256 hashes of both archives.

See the [installation guide](https://github.com/RyoOuchi/Presmith/blob/v0.2.1/docs/install.md).
Homebrew supplies Node.js 24; manual installations need Node.js 22+ and npm for
browser operations. Skill installation and deck initialization work offline.

## Preview limitations

This release targets Apple Silicon Macs running macOS 14 or newer. Linux,
Windows, and Intel Mac release binaries are not verified. The CLI remains unsigned
and unnotarized by Developer ID. PowerPoint and Google Slides import appearance
and native operating-system IME behavior have not been manually verified.
