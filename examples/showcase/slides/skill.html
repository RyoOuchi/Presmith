04 / The Codex skill

A prompt becomes a working deck

The skill gives Codex a concrete authoring and review process.

EXAMPLE REQUEST

“Use $presmith to create an eight-slide engineering proposal. Use these incident notes as facts. End with the decision we need.”

A clear audience, source material, and purpose
give the story direction.

  1. 01

    Read & outline

    Inspect the project and Git changes.
    Give each slide one main point.

  2. 02

    Author the source

    Use shared styles and local assets.
    Preserve facts and source attribution.

  3. 03

    Inspect & revise

    Run checks. Open the rendered images.
    Repair issues before handing off.
