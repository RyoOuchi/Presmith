# Presmith v0.2.0

The first Presmith prerelease brings a local presentation CLI, a visual editor,
and a Codex authoring skill together around editable HTML source files.

## What's included

- `presmith init` creates a complete three-slide project with themes and runtime assets.
- `presmith dev` previews slides with live reload; `presmith edit` opens the visual editor.
- Edit text, typography, colors, spacing, images, notes, and slide order, with undo/redo,
  explicit Save, and conflict detection for changes made outside the editor.
- Check browser diagnostics, render PNGs and contact sheets, and export HTML, PDF,
  or editable PowerPoint files with raster fallbacks for unsupported elements.
- Use the bundled `$presmith` skill for briefs, outlines, scripts, source material,
  revisions, and visual verification.
- Existing Decksmith decks retain their project format, output paths, and runtime API.

## Downloads and installation

- **CLI:** `presmith-v0.2.0-aarch64-apple-darwin.tar.gz` — Apple Silicon macOS binary,
  installation guide, MIT license, dependency notices, and build information.
- **Optional plugin:** `presmith-plugin-v0.2.1.tar.gz` — plugin manifests and the
  self-contained authoring skill. The plugin has its own version number.
- **Checksums:** `SHA256SUMS` — SHA-256 hashes of both archives.

Follow the [installation guide](https://github.com/RyoOuchi/Presmith/blob/v0.2.0/docs/install.md).
Node.js 22+ and npm are required for browser operations; `presmith setup` installs
project-local renderer dependencies and Chromium. Rust is needed only to build
from source:

```sh
cargo install --git https://github.com/RyoOuchi/Presmith.git --tag v0.2.0 --locked
presmith init my-talk
cd my-talk
presmith setup
presmith edit --open
```

## Validation

The release passed 29 Rust tests, 17 browser integration checks, and 19 visual-editor
integration checks. Both browser suites ran against the extracted release binary.
A fresh project downloaded its renderer and Chromium, passed diagnostics, rendered
PNGs, and exported HTML, PDF, and PPTX. Skill and plugin validation also passed.

## Preview limitations

This release targets Apple Silicon Macs. Linux, Windows, and Intel Mac binaries
are not verified. The downloadable CLI is not Developer ID signed or notarized;
see the installation guide for first-launch guidance or build from source.

PowerPoint structures and exported content are tested, but Office/Google Slides
import appearance and native operating-system IME behavior have not been manually
verified. Complex CSS and SVG may rasterize, and fonts can substitute in Office.
The tool is intended for trusted local project sources.

Presmith is MIT licensed. Third-party components retain their own licenses, which
are included with the CLI distribution.
