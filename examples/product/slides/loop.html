The workflow / source to screen

A short loop.
A better-informed next edit.

  1. 01 / CREATE

    Start with the story.

    Initialize a project.
    Ask Codex for an outline
    and a first set of slides.

  2. 02 / INSPECT

    See what you made.

    Preview in the browser.
    Check layout and assets.
    Open the rendered images.

  3. 03 / REFINE

    Fix what matters.

    Make a focused revision.
    Inspect it again.
    Export HTML or PDF.
